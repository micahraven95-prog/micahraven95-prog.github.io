# BoldT Team developer website

GitHub Pages user site for BoldT Team, the developer of LipTry: https://micahraven95-prog.github.io/

- `index.html`: developer page linking to the LipTry privacy policy and contact email.
- `app-ads.txt`: authorized ad sellers for BoldT Team's AdMob account (publisher `pub-1991260993487357`), served at https://micahraven95-prog.github.io/app-ads.txt. Keep it identical to the line shown in AdMob → Apps → app-ads.txt.
- `.nojekyll`: serve files as-is.

Use `https://micahraven95-prog.github.io` as the **Website** in Google Play Console (Store presence → Store settings → Store listing contact details). AdMob looks for `app-ads.txt` at the root of that domain.

Pure HTML and CSS: no JavaScript, analytics, trackers, ads, external fonts or cookies. The privacy policy itself lives in the separate `LipTry-Privacy` repository.
